The book is written to be read in order. One website grows from chapter to
chapter, and each chapter starts from the result of the one before. These paths
suggest where to put your time depending on what you already know, but every
path builds the same site.

If you skim a chapter, still do its exercises quickly: the next chapter expects
their result. Downloadable chapter checkpoints, so you can start midway without
repeating earlier steps, are planned.

## New to building websites {#new}

You can manage files and install software, but you have not built a website,
used a terminal, or used Git.

1. Read [Chapters 1](../book/chapter_01_your_first_hugo_website/) to
   [7](../book/chapter_07_publish_your_hugo_site_with_github_pages/) in order
   and do every exercise. By the end of Chapter 7, your site is published at a
   public address.
2. Read [Chapter 8](../book/chapter_08_work_with_an_ai_agent_on_your_hugo_site/)
   before asking an AI agent to change anything. It shows how to give an agent
   one bounded task and check what it actually changed.
3. Continue with Chapters 9 to 19 at your own pace.

## Some web experience {#some-experience}

You have written HTML and CSS or run a site in a content management system, but
you have not used a static site generator or Git.

1. Work through [Chapters 1](../book/chapter_01_your_first_hugo_website/) to
   [3](../book/chapter_03_organise_a_useful_website/) quickly. They set up the
   project every later chapter builds on.
2. Skim [Chapter 4](../book/chapter_04_understand_the_html_behind_your_pages/)
   (HTML) and [Chapter 5](../book/chapter_05_practical_css_for_your_hugo_site/)
   (CSS), but do their exercises: later chapters edit the same files.
3. Read [Chapter 6](../book/chapter_06_track_and_recover_your_hugo_site_with_git/)
   (Git) and [Chapter 7](../book/chapter_07_publish_your_hugo_site_with_github_pages/)
   (publishing) carefully. This is where the workflow differs most from a
   content management system.
4. Continue from [Chapter 8](../book/chapter_08_work_with_an_ai_agent_on_your_hugo_site/).

## Developers {#developers}

You use Git and a terminal every day and want the agent-assisted publishing
workflow.

1. Do [Chapter 1](../book/chapter_01_your_first_hugo_website/) for the project
   setup, then move briskly through Chapters 2 to 7 to build the same site.
2. Spend your time on working with agents, from a bounded edit in
   [Chapter 8](../book/chapter_08_work_with_an_ai_agent_on_your_hugo_site/) to
   sourced content in
   [Chapter 13](../book/chapter_13_create_and_maintain_content_with_ai_agents/);
   on Hugo templates and data in
   [Chapters 10](../book/chapter_10_use_hugo_templates_to_display_your_content/)
   to [12](../book/chapter_12_build_a_resource_directory_with_json/); and on
   checking every contribution in
   [Chapter 14](../book/chapter_14_check_every_contribution_with_ci_cd/).
3. [Chapter 17](../book/chapter_17_add_interactive_features_responsibly/)
   covers what a static site cannot do by itself, and
   [Chapter 18](../book/chapter_18_maintain_migrate_and_recover/) covers
   maintenance and recovery after a change is already live.

## Teachers and teams {#teams}

You maintain a site with other people, or you plan to teach this material.

1. [Chapters 8](../book/chapter_08_work_with_an_ai_agent_on_your_hugo_site/)
   and [13](../book/chapter_13_create_and_maintain_content_with_ai_agents/):
   how agent contributions are bounded, sourced, and reviewed.
2. [Chapter 14](../book/chapter_14_check_every_contribution_with_ci_cd/):
   requiring checks before a change can be merged.
3. [Chapter 16](../book/chapter_16_publish_in_multiple_languages/): publishing
   in a second language, including right-to-left languages such as Kurdish and
   Arabic.
4. [Chapter 18](../book/chapter_18_maintain_migrate_and_recover/):
   maintenance, credentials, licensing, and ownership.
5. [Chapter 19](../book/chapter_19_build_your_own_publishing_project/):
   planning a project with named authors, reviewers, and maintainers.
